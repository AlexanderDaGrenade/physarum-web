## The problem

A dashboard product that had grown slow and fragile, with every change risking a regression.

## The path

- Rebuilt the front-end in Next.js and TypeScript on top of a typed API layer.
- Introduced a small design system so new screens stopped reinventing components.
- Set up CI, previews and handover docs so the client's team could own it.
