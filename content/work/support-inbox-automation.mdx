## The problem

A growing support inbox, a small team, and the same twenty questions over and over.

## The path

- Mapped ticket categories and which ones were safe to automate.
- Built a triage-and-draft agent connected to orders and policies, with a human approving every send at first.
- Added monitoring so quality is measured, not assumed.
